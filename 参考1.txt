## 一、技术栈全景

| 层级 | 技术选型 | 版本要求 |
|------|----------|----------|
| **SDK** | .NET 10 SDK | 10.0.100+（LTS，支持至2028年） |
| **UI框架** | Avalonia UI | 12.0.0+ |
| **UI主题** | Avalonia.Themes.Fluent | 12.0.0+ |
| **MVVM框架** | CommunityToolkit.Mvvm | 8.4.0+ |
| **数据存储** | Microsoft.Data.Sqlite | 8.0.0+（内置AOT兼容） |
| **JSON序列化** | System.Text.Json（源生成器模式） | .NET 10内置 |
| **依赖注入** | Pure.DI 或 Microsoft.Extensions.DependencyInjection | 编译期注入，零反射 |

> **关键约束**：Android 和 iOS 平台**必须使用 .NET 10**，Avalonia 12 已不再支持更低版本。

### 2.2 主项目 .csproj 完整配置

```xml
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <OutputType>WinExe</OutputType>
    <TargetFramework>net10.0</TargetFramework>
    <Nullable>enable</Nullable>
    <TrimMode>full</TrimMode>
    <InvariantGlobalization>true</InvariantGlobalization>
    
    <!-- ═══ Native AOT 核心配置 ═══ -->
    <PublishAot>true</PublishAot>
    <PublishTrimmed>true</PublishTrimmed>
    <IlcTrimMetadata>true</IlcTrimMetadata>
    
    <!-- ═══ Avalonia 编译绑定（AOT 必需）═══ -->
    <AvaloniaUseCompiledBindingsByDefault>true</AvaloniaUseCompiledBindingsByDefault>
    
    <!-- ═══ 兼容性配置 ═══ -->
    <IsAotCompatible>true</IsAotCompatible>
    <BuiltInComInteropSupport>false</BuiltInComInteropSupport>
  </PropertyGroup>

  <!-- ═══ NuGet 包引用 ═══ -->
  <ItemGroup>
    <!-- Avalonia 12 核心包 -->
    <PackageReference Include="Avalonia" Version="12.0.0" />
    <PackageReference Include="Avalonia.Desktop" Version="12.0.0" />
    <PackageReference Include="Avalonia.Themes.Fluent" Version="12.0.0" />
    <PackageReference Include="Avalonia.Fonts.Inter" Version="12.0.0" />
    
    <!-- 移动端支持（自动适配平台） -->
    <PackageReference Include="Avalonia.Android" Version="12.0.0" />
    <PackageReference Include="Avalonia.iOS" Version="12.0.0" />
    
    <!-- MVVM 源生成器（AOT 友好） -->
    <PackageReference Include="CommunityToolkit.Mvvm" Version="8.4.0" />
    
    <!-- 数据存储 -->
    <PackageReference Include="Microsoft.Data.Sqlite" Version="8.0.0" />
    
    <!-- 调试支持（可选，Release 会自动排除） -->
    <PackageReference Include="AvaloniaUI.DiagnosticsSupport" Version="2.2.0" />
  </ItemGroup>

  <!-- ═══ AOT 修剪根（防止关键程序集被误删）═══ -->
  <ItemGroup>
    <TrimmerRootAssembly Include="CommunityToolkit.Mvvm" />
    <TrimmerRootAssembly Include="Microsoft.Data.Sqlite" />
  </ItemGroup>
</Project>
```

> **配置要点**：
> - `PublishAot=true` 是主可执行项目的必需项
> - `IsAotCompatible=true` 应添加到所有项目/库中
> - `AvaloniaUseCompiledBindingsByDefault=true` 在 v12 中已是默认值

## 四、数据存储

### 4.1 SQLite（推荐用于复杂查询）

```csharp
// FamilyTreeApp/Services/DatabaseService.cs
using Microsoft.Data.Sqlite;

public class DatabaseService : IDisposable
{
    private readonly SqliteConnection _connection;
    
    public DatabaseService(string dbPath)
    {
        _connection = new SqliteConnection($"Data Source={dbPath}");
        _connection.Open();
        InitializeTables();
    }
    
    private void InitializeTables()
    {
        var command = _connection.CreateCommand();
        command.CommandText = @"
            CREATE TABLE IF NOT EXISTS People (
                Id TEXT PRIMARY KEY,
                Name TEXT NOT NULL,
                Gender TEXT,
                BirthDate TEXT,
                PhotoPath TEXT
            );
            CREATE TABLE IF NOT EXISTS Relationships (
                Id TEXT PRIMARY KEY,
                FromPersonId TEXT NOT NULL,
                ToPersonId TEXT NOT NULL,
                RelationType TEXT NOT NULL,
                Properties TEXT
            );
        ";
        command.ExecuteNonQuery();
    }
    
    public void SavePerson(Person person)
    {
        // 实现保存逻辑
    }
    
    public List<Person> LoadAllPeople()
    {
        // 实现加载逻辑
        return new List<Person>();
    }
}
```

### 4.2 JSON 文件存储（更轻量，需源生成器）

```csharp
// FamilyTreeApp/Services/JsonContext.cs
using System.Text.Json.Serialization;

[JsonSerializable(typeof(FamilyTreeData))]
[JsonSerializable(typeof(List<Person>))]
[JsonSerializable(typeof(List<Relationship>))]
public partial class FamilyTreeJsonContext : JsonSerializerContext
{
    // 源生成器自动生成序列化代码
}

// 使用方式
public class FamilyTreeData
{
    public List<Person> People { get; set; } = new();
    public List<Relationship> Relationships { get; set; } = new();
}

// 序列化/反序列化
var data = JsonSerializer.Deserialize(json, FamilyTreeJsonContext.Default.FamilyTreeData);
var json = JsonSerializer.Serialize(data, FamilyTreeJsonContext.Default.FamilyTreeData);
```

> **关键警告**：在 Native AOT 环境下，**绝对不能使用**基于反射的 JSON 序列化（即不带源生成器的 `JsonSerializer.Serialize(obj)`），否则运行时将抛出异常。

## 五、UI 与图表展示

### 5.1 关系图谱可视化选项

Avalonia 官方提供了多种图表方案：

| 图表类型 | 适用场景 | 来源 |
|----------|----------|------|
| **Organization Chart（组织结构图）** | 家族树、谱系图 |  |
| **Radial Tree Chart（径向树图）** | 以某人为中心的辐射式展示 |  |
| **Force-Directed Graph（力导向图）** | 复杂关系网络展示 |  |
| **Dendrogram（树状图）** | 层级关系展示 |  |

> **注意**：高级图表功能需要 **Avalonia Pro** 订阅。因此不使用 Pro，需要自行基于 `ItemsControl` 或第三方库（如 `LiveCharts2`）实现。

### 5.2 XAML 视图示例（使用编译绑定）

```xml
<!-- FamilyTreeApp/Views/MainView.axaml -->
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:vm="using:FamilyTreeApp.ViewModels"
             x:DataType="vm:MainViewModel"
             x:CompileBindings="True">
    <DockPanel>
        <!-- 标题 -->
        <TextBlock DockPanel.Dock="Top" Text="{Binding Title}" FontSize="24" Margin="10"/>
        
        <!-- 人员列表 -->
        <ListBox DockPanel.Dock="Left" Width="250"
                 ItemsSource="{Binding People}"
                 SelectedItem="{Binding SelectedPerson}">
            <ListBox.ItemTemplate>
                <DataTemplate x:DataType="models:Person">
                    <TextBlock Text="{Binding Name}" />
                </DataTemplate>
            </ListBox.ItemTemplate>
        </ListBox>
        
        <!-- 详情区域 -->
        <StackPanel Margin="10">
            <TextBlock Text="{Binding SelectedPerson.Name, FallbackValue='请选择人员'}" />
            <!-- 更多详情和关系计算按钮 -->
            <Button Command="{Binding CalculateRelationCommand}"
                    CommandParameter="{Binding SelectedPerson}"
                    Content="计算关系" />
        </StackPanel>
    </DockPanel>
</UserControl>
```

> **AOT 关键要求**：每个 `{Binding}` 都必须配合 `x:DataType` 和 `x:CompileBindings="True"`，否则在 AOT 环境下会失败。

## 七、必须遵守的 AOT 规则

### ✅ 可以做（安全）

| 操作 | 说明 |
|------|------|
| 使用 `CommunityToolkit.Mvvm` 源生成器 | 编译时生成代码，零反射 |
| 使用 `System.Text.Json` 源生成器 | 必须显式声明 `[JsonSerializable]` |
| 使用 XAML 编译绑定 | 设置 `x:CompileBindings="True"` |
| 使用 `TrimmerRootAssembly` | 防止关键程序集被修剪 |
| 使用静态资源引用 | 避免 `DynamicResource` |

### ❌ 禁止（AOT 不兼容）

| 操作 | 后果 |
|------|------|
| `Activator.CreateInstance("类型名字符串")` | 运行时找不到类型 |
| `Assembly.Load` 或动态加载程序集 | 编译时无法静态分析 |
| `System.Reflection.Emit` | AOT 环境完全不支持 |
| 无源生成器的 `JsonSerializer.Serialize(obj)` | 抛出 `InvalidOperationException` |
| 反射式 ViewLocator | 视图无法找到 |
| 动态 XAML 加载 | 运行时解析失败 |

### ⚠️ 需要特殊处理

- **第三方控件**：需确认其 AOT 兼容性，或添加 `TrimmerRootAssembly`
- **动态控件创建**：需在修剪配置中显式保留

## 八、总结

**Avalonia 12 + .NET 10 Native AOT** 在 2026 年 8 月已是经过验证的生产级方案：

1. **Avalonia 12** 重构了 Android 后端，Native AOT 下启动速度提升 4 倍

3. **编译绑定**默认开启，完美适配 AOT
4. **体积控制**理想（桌面 <12MB，移动端 <20MB）
5. **开发效率**高：一套代码、XAML 声明式 UI、C# 业务逻辑全平台复用

按照上述技术栈和配置实施，可确保应用在 Windows、Android、iOS 上均能以最小体积、最快速度运行。
